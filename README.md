# LENS AI - Real-Time Object Detection System

An AI-powered real-time object detection pipeline that identifies and localizes multiple objects in images and live video streams using YOLOv8 & OpenCV.

## 🚀 Features
- Real-time detection at 30+ FPS on webcam feed
- Multi-object detection with bounding boxes & confidence scores
- Supports 80+ COCO object classes (person, car, dog, etc.)
- Works on images, videos, and live camera

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** OpenCV, PyTorch, Ultralytics YOLOv8
- **Concepts:** Computer Vision, Deep Learning, SSD, YOLO
